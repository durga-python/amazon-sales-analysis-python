# Amazon E-Commerce Sales Analysis

## Project Overview

This project analyzes Amazon sales data to understand revenue trends, category performance, regional sales distribution, customer segments, and operational efficiency.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Analysis Performed

* Data Cleaning
* Revenue Analysis
* Category Analysis
* Geographic Analysis
* Monthly Revenue Trends
* Order Status Analysis
* Cancellation Analysis
* B2B vs B2C Analysis
* Top Product Analysis

## Key Findings

* Total Revenue: ₹7.86 Crore
* Top Category: Set
* Top State: Maharashtra
* Cancellation Rate: 14.21%
* Revenue declined from April to June 2022
* B2C customers generated the majority of revenue

## Business Recommendations

* Reduce order cancellation rates
* Improve inventory planning
* Expand high-performing product categories
* Strengthen presence in top-performing states
* Explore B2B growth opportunities
